WATCH AUTH PRO — AUTHENTICATION WORKSTATION PROTOTYPE

This branch is a clean-room test of a new WatchAuthPro architecture.

CORE MODEL
Expected watch -> Observed watch -> Discrepancies -> Bench actions

THIS PROTOTYPE INCLUDES
- Watch intake by brand, case reference, serial and workflow type
- Safety gate before normal bench workflow
- Exact, family, review and unknown mapping states
- Expected-vs-observed comparison
- Live match/conflict/pending states
- Discrepancy significance and investigation guidance
- Evidence matrix
- Dynamic next bench actions
- Progressive disclosure for reference, serial and provenance intelligence
- Unknown-reference behaviour that asks for research rather than inventing data

TEST RECORDS
- Rolex 126610LN
- Tudor 25600T
- Breitling A13340
- Sinn UX

IMPORTANT
The reference records in this prototype are demonstration data and are not a production authentication authority. The production rebuild should use structured, source-backed, field-level evidence with confidence and verification metadata.

The legacy embedded data file has intentionally been removed from this branch.
