# Missing-reference completion rule

After researching a queued reference, do not leave the queue status as an
unexamined final step. Every research release must reconcile its queue entries.

1. Read the original request and exact brand/reference. Decide whether the
   published work answers that request. A completed missing-lookup request can
   be resolved while normal physical inspection and documented photo gaps remain.
2. Publish and verify the researched mapping on BenchAuth OLD first.
3. Mark the matching request **resolved** when the original request is answered.
   Do not close it merely because a family mapping or some photographs exist.
   Keep unresolved identity, variant or observed-calibre conflicts active.
4. Preserve the original question, author and creation time. Save a private
   before/after snapshot and guarded rollback; change only the selected status.
5. Read the queue again and verify the update and that other rows were unchanged.
   Record the resolution and any residual limits in PHOTO_RESEARCH.md.

Resolved entries stay in history, disappear from the default active list, and can
be viewed with **Show resolved** or reopened by an administrator. An import or
rule with manualReview is not a reliable automatic completion signal.
